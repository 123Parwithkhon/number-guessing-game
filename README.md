---

## 🎮 Game Rules
1. The computer randomly selects a secret number between **1 and 100**.
2. Enter your guess in the input field and click **GUESS**.
3. The game provides real-time feedback:
   - 📉 Tells you if your guess is **too low**.
   - 📈 Tells you if your guess is **too high**.
   - 🎉 Congratulates you when you guess the **correct number** and locks further inputs.
4. Keeps track of the total number of attempts and displays all previously guessed numbers.

---

## ✨ Features
- **Dynamic Feedback System:** Instant visual updates after each attempt.
- **Input Validation:** Prevents out-of-bounds guesses (numbers outside the 1–100 range).
- **History Tracking:** Displays previously entered numbers to help refine your strategy.
- **Modern UI Styling:** Styled with vibrant CSS gradients, centered layout, and clean Google Fonts (`Poppins`).

---

## 🛠️ Tech Stack & Concepts Applied
- **HTML5:** Semantic layout, form controls, and web typography integration.
- **CSS3:** Linear gradients, CSS Grid, absolute positioning, and responsive design elements.
- **Vanilla JavaScript (DOM Manipulation):**
  - Event handling and user input processing.
  - Pseudo-random number generation (`Math.random()`).
  - Conditionals, state tracking (arrays & counters), and dynamic DOM content updates.
