A clean, responsive, and interactive web-based **Number Guessing Game** built with HTML5, CSS3, and Vanilla JavaScript. 

---

## 🎮 Game Rules
1. The computer randomly selects a number between **1 and 100**.
2. Enter your guess in the input field and click **GUESS**.
3. The game provides real-time feedback:
   - 📉 Tells you if your guess is **too low**.
   - 📈 Tells you if your guess is **too high**.
   - 🎉 Congratulates you when you guess the **correct number** and disables further inputs.
4. Keeps track of the total number of attempts and displays all previously guessed numbers.

---

## ✨ Features
- **Dynamic Feedback System:** Instant visual feedback after each attempt.
- **Input Validation:** Prevents out-of-bounds guesses (numbers outside 1–100).
- **History Tracking:** Displays previously entered numbers to help refine your next guess.
- **Modern UI Styling:** Styled with vibrant CSS gradients, smooth layouts, and clean Google Fonts (`Poppins`).

---

## 🛠️ Tech Stack & Concepts Applied
- **HTML5:** Semantic layout, form controls, and web typography integration.
- **CSS3:** Linear gradients, CSS Grid, absolute positioning, and dynamic UI elements.
- **Vanilla JavaScript (DOM Manipulation):**
  - Event handling (`onclick`).
  - Pseudo-random number generation (`Math.random()`).
  - Conditionals, state tracking (arrays & counters), and DOM content updates.
